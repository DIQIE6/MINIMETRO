# 在 macOS 上运行 · 给朋友的说明

这是我自己做的 **Mini Metro（迷你地铁）复刻版**。下面三步以内就能玩上。

> **先看清楚：要玩必须把整个文件夹一起拿过去**，不能只拿某一个文件。
> 收到的是一个 zip 就整个解压出来。

---

## 方式一：只想先随便玩玩（不用装任何东西）

解压后，直接双击这个文件：

```
dist/minimetro.html
```

它会用你默认的浏览器打开，**完全离线、不需要 Node.js、不需要联网**。

- ✅ 普通模式、无尽模式、所有玩法都在
- ❌ 联机模式用不了（联机需要下面的方式二）

> 如果双击只是「用文本编辑器打开了它」，右键它 → **打开方式** → 选 **Google Chrome / Safari** 就行。

---

## 方式二：完整版（想联机和朋友一起比）

需要装一次 **Node.js**（免费，装完就不用管了）：

1. 打开 <https://nodejs.org> → 下载 **LTS** 版的 macOS 安装包（`.pkg`）→ 双击安装
2. 回到解压出来的文件夹，**双击 `start-mac.command`**
   → 浏览器会自动打开游戏，终端窗口会打印地址

关闭那个终端窗口就等于关掉服务。

---

## 方式三：联机（同图竞速）

**当主机的那个人**：双击 `start-online-mac.command`

终端里会打印类似这样的地址：

```
Mini Metro 联机主机  http://127.0.0.1:8123/
  局域网内其他人打开:  http://192.168.1.23:8123/
```

**把这个 `192.168.x.x` 或 `10.x` 的地址发给我**（别发 `127.0.0.1`，那是主机自己）。

**其他人**：和主机连**同一个 WiFi**，用浏览器打开那个地址 →
选「**联机模式**」→ 输入主机屏幕上的 **4 位房间号** → 主机点「开始比赛」。

规则：**所有人跑同一张地图**，各修各的地铁网，**活最久的人赢**。

## 如果 macOS 不让打开（很常见，不是文件坏了）

第一次运行时 macOS 会拦一下，因为它是我自己做的、没有苹果签名。任选一种：

**办法 A（推荐）**：在 `start-mac.command` 上**右键** → 「**打开**」→ 在弹窗里再点一次「**打开**」。
只需要做一次，以后双击就行。

**办法 B（一行命令搞定所有）**：打开「终端」（Terminal），粘贴：

```bash
cd ~/Downloads/MiniMetro && chmod +x *.command && xattr -dr com.apple.quarantine . && ./start-mac.command
```

> 把 `~/Downloads/MiniMetro` 换成你实际解压的位置（也可以直接把文件夹从访达拖进终端，它会自动补全路径）。
> `chmod +x` 是必须的：**zip 不支持保存「可执行」权限**，所以我打包时给了也没用，macOS 这边要自己赋一次。

## 玩法速查

新车站不断冒出来，**乘客只想去和自身形状相同的车站**。用有限的线路、隧道、车头把大家送到目的地，别让站台挤爆。

| 操作 | 结果 |
| --- | --- |
| 从**车站**本身拖出去 | 在这里开一条新线 |
| 拖线路两端的 **T** | 延长这条线 |
| 拖 T **划过**沿线某个车站 | 把那个站从这条线摘掉 |
| 拖 T 到**对端终点站** | 闭合环线 |
| 按住线路**中段**拖动 | 改道 |
| **右键**线路上的车站 | 直接摘除 |
| 底部**车头**拖到线路 | 这条线开出一列车 |
| 底部**车厢**拖到列车 | 加挂一节 |
| 底部**隧道**拖到山地 | 翻山改成穿隧道（不减速） |

**过河会自动消耗隧道，不用手动放。**

游戏里点「**规则说明**」有完整版：每种车站的客流去向、所有数值和机制都在里面。

## 常见问题

**双击没反应？**
多半是没有执行权限。用上面「办法 B」那行命令。

**提示找不到 Node.js？**
方式一不需要它；方式二、三需要。到 <https://nodejs.org> 装 LTS 版即可。

**联机时别人打不开我发的地址？**
- 确认发的是 `192.168.x.x` / `10.x` 开头的地址，不是 `127.0.0.1`
- 确认在同一个 WiFi（公司/学校的网络可能禁止设备互访，换手机热点最快）
- macOS 可能会弹窗问「是否允许 node 接受传入连接」→ 点**允许**

**能离线玩吗？**
能，方式一完全离线。联机需要同一个局域网内有一台机器当主机。
