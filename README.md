# Mini Metro · 复刻版

> **开发记录：[WORKLOG.md](WORKLOG.md)** —— 项目完整工作流存档（做了什么、修过哪些 bug、当前数值与待办）。
> 约定：**每做完一部分内容就更新那个文件**。


一个用原生 JavaScript（ES Modules + Canvas 2D）从零实现的迷你地铁（Mini Metro）复刻版。
**零依赖**：不需要 `npm install`，克隆下来就能跑。

```
┌─ 线路两端画着 T 形标记：拖动 T 延长这条线
├─ 拖 T 到另一端的 T 上 → 闭合成环线，列车开始无限循环
├─ 直接从车站本身拖出去 → 在这里开一条新线；没接上第二个站就自动丢弃
├─ 按住两点之间的轨道拖动 → 两端邻居不变，把这段线改接到另一个车站
├─ 右键线路上的车站 → 摘掉它，两端邻居自动相连
├─ 改道时旧线路上有车 → 旧线路和车都变淡，车到下一站后再切换或回收
├─ 底部托盘可以拖车头/车厢上线，也可以把整列车从一条线拖到另一条线
├─ 过河段画成虚线；轨道穿过别的车站时画一条细白斜杠表示"只是路过"
└─ 站台排队超过容量 42 秒 → 普通模式游戏结束
```

轨道只用**水平 / 垂直 / 45°**三种走向，拐弯一律 135° 或 90°，并且用**圆角**连接，
不会出现很斜的线。列车**站间加速巡航、进站前减速**，站台处会明显慢下来。
车厢画得足够大，**车里的乘客会按各自想要的形状画在座位上**，一眼就能看出这趟车在替谁跑腿。

## 快速开始

### 方式一：单个 HTML 文件（最简单）

直接双击 `dist/minimetro.html`。所有 CSS 和 17 个模块都已经内联，`file://` 下即可运行。

重新生成：

```bash
node tools/build.mjs
```

### 方式二：本地静态服务器（开发用）

ES Modules 不能通过 `file://` 加载，所以开发版本需要一个静态服务器：

```bash
node tools/serve.mjs            # 默认 http://127.0.0.1:8123/
node tools/serve.mjs --port 9000
```

Windows 上也可以直接双击 `start.cmd`，它会启动服务器并打开浏览器。

### 双击启动（不用命令行）

启动器会自动打开浏览器。**浏览器里的网页无法启动本地服务，所以是主机反过来去开浏览器。**

| 系统 | 单机 | 联机主机 |
| --- | --- | --- |
| Windows | `start.cmd` | `start-online.cmd` |
| macOS | `start-mac.command` | `start-online-mac.command` |
| 任意系统（离线单机，不需要 Node） | 双击 `dist/minimetro.html` | — |

macOS 用户请看 [README-mac.md](README-mac.md)：里面有 Gatekeeper 拦截的处理办法
（右键 → 打开，或 `chmod +x *.command` 加 `xattr -dr com.apple.quarantine .`）。
**zip 不保存 Unix 可执行位**，所以 Mac 上第一次必须先 `chmod +x` 一次。

要整包发给别人，用打好的 `D:\DeepseekHarness\MiniMetro-latest.zip`。

### 联机

```bash
node tools/net-server.mjs         # 或双击 start-online.cmd / start-online-mac.command
```

它会打印本机的局域网地址，其他人用浏览器打开那个地址即可（**不需要装任何东西**）。
进入游戏后选「联机模式」→ 房主「创建房间」→ 其他人输房间号 → 房主开始。
所有人跑同一张地图，活得最久的人赢。

## 玩法

**建线（拖动）**

线路的两个终点站会向外伸出一个 **T 形标记**，那就是这条线的「接口」；
车站本身则是「在这里开一条新线」的入口。两种手势互不干扰。

| 操作 | 说明 |
| --- | --- |
| **单击**车站 | 什么都不发生（不会误建线路） |
| **拖动端点上的 T** | 延长这条线：线条跟着鼠标走，**路过的车站依次接上**，松手就连上 |
| 把 T 拖到另一端的 T 上 | 闭合成**环线**（环线没有端点，也就没有 T） |
| 拖回起点方向 | 依次撤销刚接上的车站 |
| **从车站本身拖出去** | 不管它是不是端点，都从它**开一条新线** |
| 松手时没接上第二个车站 | 新线**自动丢弃并退还槽位** |
| `Esc` / 右键空白处 | 取消这次拖动 |
| 线路托盘上的 `×` | 停运这条线路（见下） |

线路颜色按顺序自动分配，车站上不再显示「下一条线的颜色」。

**改道（按住线路本身）**

| 操作 | 说明 |
| --- | --- |
| **按住两点之间的轨道**拖动 | 抓起的这段线跟着鼠标走，**两端邻居不变**；松手落在某个车站上，线路就改从它经过 |
| **右键**线路上的车站 | 把它从线路上摘掉，两端邻居自动相连 |
| `Esc` | 取消这次拖动 |

**车辆（底部托盘）**

托盘里「车头」和「车厢」两个筹码显示**可用 / 总数**，都可以直接拖到线路上：

| 操作 | 说明 |
| --- | --- |
| 把**车头**拖到线路上 | 新画的线路**自动附带一个车头**；再拖一个上去，这条线就**多一列火车**（一条线可以跑任意多列，互不相撞，也可以反着开）。车头**就落在你松手的位置**上，并且**朝着更近的那个车站**（车头方向跟着走） |
| 把**车厢**拖离列车 | 单独拆下一节车厢，丢到别的列车上是**换挂**，丢在空白处就**退回托盘** |
| 拖动列车（按住车头） | 拖到同一条线的别处＝**在线内调度**；拖到另一条线＝整列转线 |
| 把**车头**拖到已有车头的线路 | 拒绝 |
| 把**车厢**拖到有车头的线路 | 载客量 +6 |
| 把**车厢**拖到没有车头的线路 | 拒绝（车厢只能挂在车头上） |
| 拖动**线路上正在跑的整列车** | 抓到另一条没车头的线路上：目标线先出现一辆**淡色占位车**，等这列车在原线路上**到站**后整车转移过去 |
| 拖到空白处松手 | 取消，什么也不发生 |

拖动时车辆**离开线路显示为灰色**，**压在线路上时显示为那条线的淡色**，松手才算数。

**一条线路可以跑多列火车**：每拖一个车头上去就多一列车。同一列车里的车厢默认**各自贴在轨道上**、
按当地切线摆放，所以过弯不会有一整条直挺挺的车厢甩出去；到站时车厢里的乘客照常下车。
如果车头池空了，托盘里的车头筹码会变灰，线路筹码标红「缺车头」。每解锁一条新线路会**附带一个车头**。

**改道 / 停运时列车怎么办**

改道会先检查**原来那条线路上有没有车**：

- **没车** —— 旧线路直接消失，没有任何过渡。
- **有车** —— 旧线路和那列车一起变成**淡色**，列车继续按旧线路跑，**到下一站**时处理：
  - 这一站**仍然在新的线路上** → 列车从这里接着跑新线路，乘客不用下车；
  - 这一站**已经不在新线路上** → 列车被**回收**（车头和车厢回到托盘），**车上乘客落在这一站**，不会凭空消失。
- 点 `×` 停运同理：轨道和槽位立刻释放，列车到下一站后回收，乘客落在站台。
- 短暂追加/缩短一端的车站不算改道 —— 旧线路还是新线路的一部分，列车**留在原地继续开**，
  既不会变淡、也不会被拉回端点站。
- 兜底 70 / 90 秒，超时同样把乘客放回车站。
- 整列车换线时，**先复位再交接乘客**（早期版本在这里丢过人），并且退役中的线路对象不会被
  重新分配给新线路。

`空格` 暂停 / 继续，`1` `2` `3` 切换 1× / 2× / 3× 速度。

**规则**

- 每名乘客只想前往**和自己形状相同**的车站；站台周围的小图形就是他们的目的地。
- 列车在线上往返行驶（环线则单向循环），沿途自动上下客。乘客会在换乘站主动下车换乘另一条线。
- 计分 = 送达乘客数；特殊车站（星形、菱形、十字、宝石）额外加分。
- 站台容量 6 人（换乘站 9 人），一列车基础载客 **6 人**。超过容量后开始 42 秒倒计时，归零即结束（无尽模式下只是清空站台并扣分）。
- 每周结束可以选择一项奖励：**新线路（附带车头） / 隧道 ×2 / 车头 / 车厢 / 换乘站**。
  - 车头和车厢进入底部托盘，拖到线路上即可部署。
  - 换乘站点击后再点到车站上安装；隧道是自动扣减的，撤回跨河段会退回。
- 一条线路只有拿到车头才会运营；没有车头的线路只画出来，乘客也不会把它算进换乘路线。

**开局资源**：3 条线路、3 个车头、3 条隧道、1 节车厢。**一天 = 10 秒**（一周 70 秒）。地图上会随机生成一条河，开局三个车站保证在同一岸。

**时间与速度**

- 游戏内**一天 20 秒**，一周 7 天 = 140 秒，也就是说大约每 2 分 20 秒拿到一次奖励。
- 单个车站的乘客生成间隔：开局 20–33 秒，随时间收紧到 7.8–13.5 秒（比上一版快约 40%）。
- 列车比车站还宽一点（27×19），因为要**把车里的乘客按目的地形状画出来**；
  站台和车厢里的乘客都是**实心形状 + 淡色光晕**，不会看不清楚。
- **河有粗有细**：主河道带随机宽度并且**向下游变宽**，支流明显更细、越靠近汇合口越宽；
  同一张图上最宽和最细能差 **4.7 倍**。
- **交汇处是一整片水**：渲染改成「先画所有河岸、再画所有水体」，所以上面那条河不会再有一条
  岸线横切过下面那条；汇合口是平滑融合而不是硬角。
- **过河的路段画成虚线**（浅色底 + 线段色虚线），一眼能看出这段是隧道。
- **地图上是一个水系**：每局 1–2 条主河道，走向随机（横、竖、斜都可能），另外有 0–1 条**支流**
  （会分叉，并常常在下游**汇入**另一条水）。
- **江心洲**由**河流分汊再合并**形成（就像橘子洲），不是凭空画一个水环——环状的河在自然界
  并不存在，所以那个生成器已经删除。实测 120 张图里 85 张有江心洲。
  河道用两条平滑正弦波塑形、控制点还做过去折角处理，所以是自然弯曲的水流而不是锯齿；支流汇入时
  会**顺着下游方向**切进去、并在汇合点后继续一小段，读起来是一条河而不是一个 T 形接口。
  穿越水面的每一处都要花一条隧道。
- **每个车站有自己的角色**：⭕住宅区（最多、客流最大）、▲商业区、■交通枢纽（最少但去的人最多）、
  ✚医院、⭐码头、◆旅游集散、⬟银行、◔公园。特殊站点每种**全局只出现一次**，并且倾向生成在地图外圈。
- 站点**不再落在一条条直线上**：位置在网格里加了抖动，并且会主动避开「和已有两个站近似共线」
  的位置（实测共线三元组 −37%、正对着的行/列站点对 11.4% → 3.9%）。
- 等车的乘客排在**车站正上方的一行**里（稍微隔开一点），不再绕着车站画一圈；
  站台和车厢里的乘客都是**实心形状、画得比较大**，不会被线路挡住。
- **所有图形按面积等比放大**：圆、三角、方、菱、星、十字、五边、扇形、宝石在同一半径下覆盖面积
  相近，不会再出现「圆明显比三角大一圈」。
- **客流方向由街区决定**（见下表），这也是「圆不会去银行」「医院只和住宅区互换」这类规则的来源：

  | 出发地 | 去向 |
  | --- | --- |
  | ⭕住宅区 | 到处都去（方形/三角各约 1/3），但**从不去银行** |
  | ▲商业区 | **93% 回住宅区**，少量去银行、码头 |
  | ■交通枢纽 | 分散，没有明显集中流向 |
  | ✚医院 | **只和住宅区互换** |
  | ⬟银行 | 住宅区为主，其次枢纽 |
  | ⭐码头 | 只去住宅区和商业区 |
  | ◆旅游集散 | 住宅区和枢纽 |
  | ◔公园 | 只去住宅区 |

  另外特殊站点平时很安静，但会不定时迎来一波**事件客流**（旅游旺季 / 比赛日 / 流感爆发），
  一次涌进 3–6 个人。
- 如果八向布线**不得不从一个不属于本线的车站身上穿过去**，那一小段轨道会画在车站之上，
  并在中间加一条**细白斜杠**（两端超出站体），表示"路过但不停"。
- 列车巡航 96 单位/秒，进站前 64 单位内按 `√距离` 减速，经过站台时只剩约 20 单位/秒；
  加速度 130 单位/秒²。实测最高 96、进站瞬间平均 26 单位/秒（更早的版本是恒定 128）。

## 代码结构

代码刻意分成「纯模拟」和「表现层」两部分，前者不碰 DOM，因此可以在 Node 里直接跑测试。

```
src/
  config.js      全部可调参数（生成速率、车速曲线、容量、计分、配色、轨道圆角）
  rng.js         可复现的随机数（mulberry32），同 seed 同结果
  geometry.js    2D 数学：线段相交、折线弧长表、Catmull-Rom 平滑
  shapes.js      车站形状定义（命中测试 / 绘制 / 乘客图标共用）
  track.js       轨道布线：只产生 0/45/90 度段，拐弯用二次曲线倒圆角
  station.js     车站：队列、容量、超载倒计时
  passenger.js   乘客（纯对象）
  line.js        线路：站序、环线、路径弧长表、跨河计数
  train.js       列车：加减速曲线、到站判定、上下客与换乘决策、旧线路冻结运行
  network.js     乘客寻路：线路图 + 换乘代价，带缓存
  river.js       河流生成与两岸判定
  game.js        游戏状态机：生成、计分、周奖励、隧道结算、点击建线/摘站（无 DOM）
  render.js      Canvas 渲染（站台、线路、列车、乘客、超载环、待连接虚线）
  input.js       指针交互：拖 T 延长 / 拖车站新建 / 拖轨道改道 / 右键摘站 / 安装资源
  hud.js         DOM HUD：分数、时钟、线路托盘、周奖励、结算面板
  autopilot.js   贪心 AI，用于演示模式与难度回归测试
  main.js        启动、主循环（固定步长）、URL 参数
tools/
  serve.mjs      零依赖静态服务器
  build.mjs      单文件打包：从 import 图推导模块顺序，检测环依赖与跨模块重名
  bundle-smoke.mjs  把打包结果放进 DOM 桩里跑一遍，确认单文件真的能启动
  balance.mjs    难度回归：用 AI 跑若干局，输出存活时间与送达量
  browser-check.html  在真实浏览器里驱动的端到端交互测试
  run-browser-check.ps1  启动 headless Edge 跑上面那个测试并回传报告
  inspect_shot.py        截图配色检查（确认画面真的渲染出来了）
tests/sim.test.mjs   Node 单元测试
```

## URL 参数（方便调试和截图）

| 参数 | 作用 |
| --- | --- |
| `?autostart=1` | 跳过主菜单直接开局 |
| `?mode=endless` | 选择模式（`normal` / `endless`） |
| `?seed=123` | 固定随机种子，复现同一张地图 |

例如：`http://127.0.0.1:8123/?demo=1&t=240&seed=42`

## 与原版的差异

这是一个**复刻**，不是移植，以下内容没有实现：

- 多张真实城市地图（伦敦 / 巴黎 / 纽约…），本作使用程序生成的随机地图
- 桥梁、第二列车、创意模式、每日挑战、音效
- 原版的固定车站位置与「特殊车站出现在地图固定点」的设定

已经实现的核心机制：形状车站与站台乘客、T 端点拖动建线与环线、拖动轨道段改道、右键摘站、
改线时冻结旧线路让车跑完再切换、停运前送完乘客、车厢内可视化乘客、
列车自动上下客与换乘、八向轨道布线 + 圆角、站间加速 / 进站减速、
跨河隧道、每周奖励与资源安装、超载倒计时与结束判定、特殊车站加分、两种模式。
